# ClashTV ⚔️

Dashboard premium para Clash Royale com TV Royale-style, busca de perfis, decks, histórico de batalhas e ranking global.

## Rodar

1. Node.js 20+
2. `npm install`
3. copie `.env.example` para `.env`
4. configure `CLASH_ROYALE_TOKEN`
5. `npm start`
6. abra `http://localhost:3000`

O token fica somente no servidor. A TV Royale do projeto monta um feed semelhante usando battle logs recentes de jogadores do ranking global; a API não fornece uma página de TV Royale pronta para terceiros.
